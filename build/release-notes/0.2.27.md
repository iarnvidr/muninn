# Muninn 0.2.27 — What's new

### Playlists
- Retry playlist metadata using the watch-and-playlist URL, with an anonymous/public listing fallback when appropriate.
- Restore a previously validated playlist queue from local storage when metadata extraction fails, clearly labelled **Saved playlist**; keep current-video playback independent.
- Clearer failure messages and Retry. A never-before-seen private or blocked playlist may still be unavailable.

### Feeds and discovery
- Show each snapshot's source kind, capture age, recorded source URL when available and search context, without inventing missing provenance.
- New **Connections** graph links capture sources, snapshots, recurring videos and channels. Inspect connections, zoom, pan and open related items.
- Refresh controls distinguish Home/Subscriptions from Search/Channel/Related captures that update through browsing.

### Browse
- Optional configurable **Muninn home** using locally captured Home, Subscriptions, Favourites and Related sections.
- Reorder, show or hide sections, and return to the embedded original YouTube experience whenever needed.
- Video cards continue opening Muninn's disk-backed local player.

### Playback and navigation
- Remove duplicate per-tab media-status icons while preserving download progress and the separate browser-tab hibernation indicator.
- Clarify mini-player **Less/More** versus **Open full player** and sidebar expansion controls.
- Make the Muninn logo open Browse.

### Install and limitations
This is a macOS Apple Silicon **prerelease** with ad-hoc Apple signing, **not notarized**. Select **Stable and previews** in Settings to receive it. A playlist without saved metadata may still be blocked by YouTube.
