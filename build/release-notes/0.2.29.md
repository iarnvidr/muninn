# Muninn 0.2.29 — Feeds you can understand, tabs that stay open

### Keep open tabs live by default
- **Automatic background tab unloading is now off by default.** An open YouTube tab remains live until you close or manually unload it.
- Existing installations are migrated from the old automatic-on default so they receive the new behavior. You can explicitly enable automatic unloading again in Settings → Browsing.
- Offline mode may still suspend remote pages; manual unloading still works. This does **not** change downloaded-media cache eviction policy.

### Feeds: visible filters and useful titles
- Replace the Kind dropdown with seven always-visible filters: All, Home, Subscriptions, Search, Channels, Related and Other.
- Related captures now record **the original video they were related to**, including a copyable watch URL and title when available. New captures show **Related to: [original title]**.
- Existing Related snapshots whose source was never recorded remain clearly marked as unknown, rather than guessing which video produced them.
- Channel captures display their verified names or YouTube handles where available, including stored older captures whose videos consistently identify a channel.
- Search snapshots show their query; repeated Home/Subscriptions captures include precise capture dates and times.
- Connections graph snapshot nodes also use these contextual titles.

### Copy and open URLs
- Copy a snapshot's YouTube source URL with one click from its Feeds row or selected-source header; **Open source** returns directly to the original video/feed.
- Copy a selected channel or video URL directly from the Connections graph inspector.
- A **Copy current tab URL** button is always available in the main navigation toolbar.
- Source links are canonicalized to avoid including tracking or sensitive query parameters.

### Validation and scope
- Linux/Dagger, native Apple Silicon, capture-provenance and UI regression checks.
- Existing local disk-backed playback, update verification and stable-only channel are unchanged.
- Apple Silicon **prerelease**, ad-hoc signed and **not notarized**. To install through Muninn, select **Stable and previews** in Settings → Muninn updates.
