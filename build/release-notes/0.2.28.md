# Muninn 0.2.28 — Redesigned Feeds network

### A graph you can actually explore
- Replaced the original crowded Feeds Connections diagram with an **organic, force-directed graph** using the same offline Cytoscape engine as Chat Hub.
- Browse captured feeds and channels as connected clusters. On selecting a channel, expand the videos actually recorded from it; selecting a video reveals its recorded channel and feed connections.
- Select nodes to highlight their neighbors and dim unrelated connections. Hover for full names, select edges for relationship evidence, or double-click to open a video, channel, or feed in Muninn.
- Search channels and video titles, zoom, pan, Fit, and move through nodes with the keyboard.
- Keep long titles readable with collision-aware labels. Limit the initial display to a manageable set of nodes rather than drawing every video at once; expand additional nodes on demand.

### Better feed provenance and presentation
- Start the network in **All loaded captures** mode, with an option to inspect only the selected capture.
- Show connection counts derived from stored capture data; only verified channel IDs are linked across captures. Missing IDs are not guessed.
- Fix the unreadable selected snapshot row in dark and classified themes.
- Include the entire graph engine and its license locally. The network works offline; no CDN or external graph service.

### Validation
- Linux/Dagger and native Apple Silicon tests, including an offline 102-video / 24-channel visual fixture.
- Native macOS screenshot reviewed for spatial layout and legibility.
- No changes to Muninn's disk-backed video playback or update signature verification.

### Installation
Apple Silicon **prerelease**, ad-hoc signed and **not notarized**. In Muninn, use Settings → Muninn updates → **Stable and previews**. Stable-only installations are unaffected.
