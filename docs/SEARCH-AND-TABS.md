# Search and tabs

Use the tab-layout button beside New tab, or Settings → Appearance → Tab layout,
to switch between horizontal and vertical tabs. The choice is saved. Both layouts
use the same tabs, groups, close controls and Ctrl+Tab navigation.

Search Muninn is available from the toolbar and Cmd/Ctrl+K, including from Browse.
Text entered in the address bar searches Muninn; an explicit URL opens directly.
Local search covers open tabs, library videos and saved channels. Saved channels
include subscriptions, channel groups and configured channels, even when their
automatic downloads are paused. Merely visiting a channel does not save it.

Every library result explicitly says **Saved** or **Not saved**, with filters for
both. A protected video or durable saved library link is Saved. Disposable cached
media is Not saved. Downloaded availability is shown separately: a saved link may
have no downloaded copy, and an unsaved video may already be downloaded. Saved
status includes all qualities of a video rather than just the displayed copy.

Typing searches local data only. To search YouTube, choose Videos, Live streams
or Channels, then select **Search YouTube**. This opens a filtered YouTube search
tab. Online search is disabled in offline mode. Queries stay in memory rather
than being saved as search history.

Outside theater mode, recommendations occupy a compact column beside the player.
They stack below only when the available player area is narrower than 560px.
Theater mode hides that column.
