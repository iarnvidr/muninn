# Search and tabs

Use the tab-layout button beside New tab, or Settings → Appearance → Tab layout,
to switch between horizontal and vertical tabs. The choice is saved. Both layouts
use the same tabs, groups, close controls and Ctrl+Tab navigation.

Search Muninn is available from the toolbar, **Cmd/Ctrl+L** and **Cmd/Ctrl+K**,
including from Browse, Player and Settings. The shortcut focuses and selects the
query without opening a tab. An explicit YouTube URL submitted there opens directly.
Local search covers open tabs, library videos and saved channels. Saved channels
include subscriptions, channel groups and configured channels, even when their
automatic downloads are paused. Merely visiting a channel does not save it.

Every library result explicitly says **Saved** or **Not saved**, with filters for
both. A protected video or durable saved library link is Saved. Disposable cached
media is Not saved. Downloaded availability is shown separately: a saved link may
have no downloaded copy, and an unsaved video may already be downloaded. Saved
status includes all qualities of a video rather than just the displayed copy.

Typing searches local data only. **Enter** (or the Search online button) fetches
YouTube results into three columns at the top: **Videos**, **Live streams**, and
**Channels**. Local results stay below. The side rail has visible filter buttons
for online types, local sources and library saved status; there are no dropdowns.
Changing a filter never starts an online request. Editing the query hides the
previous online results until another Enter; late responses cannot replace a
newer search. Offline mode blocks online submissions while local results remain
available. Queries and online results stay in memory rather than search history.

From the query, **Down** enters results. While a result or type heading has
focus, **Up/Down** or **k/j** move through results, and **Left/Right** or **h/l**
move between types, retaining the row where possible. Moving past the end of an
online column continues into the matching local column; moving up returns to
online results. **Enter** opens the focused result, and **Escape** returns to the
query. Letter keys remain normal typing in the query field. Tab navigation also
remains available.

Outside theater mode, recommendations occupy a compact column beside the player.
They stack below only when the available player area is narrower than 560px.
Theater mode hides that column.
